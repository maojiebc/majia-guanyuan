# 受限环境取数速查

普通查询继续使用官方 CLI；SQL 接口不可用、汇总不能依赖样本、分块读取或需要数字出处时，先读本手册。这里补充查询策略与证据管理，不提供另一套 BI 接口。

以下为某租户实测经验与本机官方帮助的对照，新环境先确认。日期是本次能定位的最早记录日期；2026-10-11 标记的项目仅能核到规划汇总/现有实现，不能声称这是故障首次发生。版本与权限不同，旧限制可能不适用。公开正文不含租户标识，原始任务证据留私有目录。

## 1. SQL 直查接口不可用

现象：`businessStatus=5001`、`Request method 'POST' is not supported`；帮助说明还要求 8.2.0-hf12+ 和高级 SQL 开关。

判断：先判断接口/版本/权限，不把它当 SQL 语法错误。

处理：小范围明细用官方 `ds preview` 加筛选；全量汇总先核专用沙箱，再使用本地 SQL 节点预览。

边界：不修改 SQL 反复提交，不开权限，不借生产 ETL 保存或运行。

首次可核记录：2026-09-15（某租户记录或官方帮助；新环境先确认）。

## 2. 两个预览名额已满

现象：`每个用户只允许提交2个运行中的预览任务`。

判断：超时的客户端退出后，远端预览可能还占名额。

处理：预览固定 `--max-parallel 1`；核对同账号其他任务和网页预览，待服务端已结束再继续。

边界：不能以睡眠时间或本地 ps 为空证明远端结束。

首次可核记录：2026-09-17（某租户记录或官方帮助；新环境先确认）。

## 3. 导出遇到游离 SQL 文件

现象：`检测到未被引用的SQL文件`。

判断：本地 etl/ 中存在没有被 ReadSQLFile 引用的 SQL。

处理：把无关 SQL 移到 etl/ 之外；保留已引用 SQL，重新 export。

边界：只整理自己的临时工作区；不改贡献者原文或线上定义。

首次可核记录：2026-09-17（某租户记录或官方帮助；新环境先确认）。

## 4. ETL 预览只显示样本

现象：结果摘要区分后端预览样本和 limit 截取行数，渲染器还可能精简；曾只看到前 200 行。`preview` 无 `-f/--format`。

判断：预览表格的行数不是物化数据集总量。

处理：在完整输入上执行 COUNT/SUM 等小结果汇总，并用同条件 rowCount 校准；记录可能截断的判断。

边界：结果碰到限制、列被精简或解析不确定时不得声称完整。

首次可核记录：2026-10-08（某租户记录或官方帮助；新环境先确认）。

## 5. 数据集预览总数与样本数不同

现象：raw 响应含 `response.rowCount`；小 limit 仍可能返回较大的 rowCount；`unknown shorthand flag: 'o'`。

判断：该字段是在当前账号权限与当前筛选下的总行数，不是全公司总量；上限为 60000。

处理：用 --raw 的 response.preview/columns 计实际返回行；只有 returned==rowCount 且 returned<limit 才接受。触顶或不一致时丢弃响应并二分日期。stdout 重定向或由包装脚本保存。

边界：不能把不同筛选的 rowCount 拼成冻结总量；先核来源版本，不能直接使用 -o。

首次可核记录：2026-09-22（某租户记录或官方帮助；新环境先确认）。

## 6. 空值筛选语法错误

现象：`操作符 EQ 需要值`。

判断：空字符串不是省略值的 EQ。

处理：空值用 IS_NULL；空字符串按字段实际能力筛选或在已确认完整的范围里本地核对。

边界：本地过滤样本不能证明全表为空。

首次可核记录：2026-09-15（某租户记录或官方帮助；新环境先确认）。

## 7. WAITING 不等于执行完成

现象：已触发任务仍显示 WAITING/PROCESSING，或等待时提示字段漂移。

判断：提交、排队、完成是不同状态。

处理：对已经合法触发的既有任务，用官方 etl get --brief --raw 回读到 FINISHED，再核输出。

边界：这条是既有任务的状态说明；只读取数脚本不能触发 run/save/schedule。

首次可核记录：2026-09-23（某租户记录或官方帮助；新环境先确认）。

## 8. 客户端超时，服务端状态未知

现象：命令 timeout 或连接中断；没有已验证可用的查询取消/终态接口。

判断：本地终止进程组只清理客户端，不证明服务端查询取消。

处理：队列暂停并记 unknown；获得服务端已结束的独立证据后再处理剩余更小范围。

边界：不能自动重试，不按时间自动解锁；权限不足也不等于没有运行任务。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 9. 临时底稿含身份信息

现象：导入底稿中出现 uId/userInfo 等身份字段。

判断：CLI 快照不等于可以公开的测试样例。

处理：证据留仓库外；默认清理整个临时工作区；保留时移除含身份信息的底稿并再次审计。

边界：不向公开仓库提交生产定义、资源 ID、令牌或真实输出。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 10. 资源权限不足

现象：指标目录、上游 ETL 定义或权限接口返回无权限/受限响应。

判断：各资源权限独立；已物化输出可读不代表上游定义也可读。

处理：记录具体受限步骤，停止该接口重试；只用账号原本可读的物化数据集做对账。

边界：不绕过权限。规划记录 guands 0.1.36 强化受限响应报错；此处不宣称本版本已完成兼容审阅或安装。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 11. 图上数值不是可相加的期间量

现象：月图启用累计计算；快照名含“近 30 天”。

判断：显示值的窗口和聚合定义决定含义，名字不能替代定义。

处理：回到带明确期间筛选的底表计算；出处记录累计/快照/去重范围，档案标明不可相加或未知。

边界：不把三个月累计显示值相加，不拿近 30 天快照当季度。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 12. 空结果与历史覆盖缺口

现象：某范围无行；当前组织或地域筛选后缺历史记录。

判断：可能是权限、筛选、上游关联当前门店资料或数据缺失。

处理：记为空结果，检查字段、范围、来源版本和历史覆盖证据。

边界：不补 0，不据此判停业；当前组织名单不证明历史全集。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 13. 候选键重复

现象：同一候选键出现多行，不同同步时间。

判断：候选键未必是业务唯一键，多行可能是合法来源。

处理：保留全部原始行，先明确粒度、退款、渠道及同步含义，再决定是否聚合。

边界：不默认取最新行去重；重复行统计与业务规则分别记录。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 14. 批量指标查询并发较高

现象：官方 metric batch-query 帮助注明固定并发 10。

判断：一次批量命令不是单个后端查询。

处理：敏感负载环境先检查请求计划与权限；需要严格串行时用单指标查询或本手册的串行数据集路径。

边界：包装命令不能把其内部并发变成 1；退出 0 不代表所有 results[].status 成功。

首次可核记录：2026-10-11（某租户记录或官方帮助；新环境先确认）。

## 只读汇总的准备

`scripts/etl_preview_aggregate.py` 只调用官方 edit/export/preview 和 ds get/preview。预览需要占用计算资源和账号名额，只读取账号原本可读的数据集。不能自动选择生产 ETL：必须由用户指定专用沙箱；单独授权新建测试沙箱时才可建立空宿主。聚合脚本内不提供新建、保存、运行或调度能力。来源版本、SQL 指纹、范围、开始/结束时间、截断和校准状态缺一不可；脚本成功也不等于业务口径正确。

本次测试发现新建宿主只申请 ID 并生成本地工作区，首次保存前未持久化，仍可 export/preview。已有宿主用 edit；这种未持久化宿主用本地种子工作区，每次复制 CLI 状态到新目录，再重新生成输入和 SQL 节点。只在用户明确授权的测试环境申请宿主，不能借此暗中增加生产资源。允许名单保存在仓库外，schemaVersion=1，hosts 数组中每项包含 profile、etlId；未持久化宿主另含 seedWorkspace。它是本地人工审阅记录，不自动证明某个 ETL 是沙箱。

```bash
python3 scripts/etl_preview_aggregate.py run \
  --profile <现有profile> --host-etl <批准的沙箱ID> \
  --allowlist /private/path/sandbox-allowlist.json \
  --input <数据集ID> --sql-file /private/path/query.sql \
  --out /private/path/run-001 --calibrate
```

输入按参数顺序对应 SQL 中的 input1/input2；只支持单条 SELECT/WITH 及可确认的字段类型，不提供任意 Go 源或用户自选命令执行。输出 SQL 列别名须为简单 ASCII 标识符，结果最多 20 行、10 列；宽字符单元格、空白单元格、表格省略、行数碰到 max-rows 或 summary 不一致均判失败。官方渲染输出有时提示使用 -f，但 preview 的帮助并未提供该参数，不能据这个提示拼出不存在的 JSON 导出命令。

result.json 保留终端单元格文本，不宣称获取了原始数字类型或完整精度；金额与比例运算需另核精度和单位。provenance.json 记录源码 SQL 哈希、来源版本/更新时间、输入、CLI 包版本、时间、截断、校准及结果文件哈希；source-note.txt 可作报告备注的出处底稿，业务期间、指标与单位由使用者补充确认。未知或空单元格不转换成零。解析不支持的结果直接失败，不能宽松拆列再称成功。

--calibrate 只允许单输入：另生成同一来源的 COUNT(*) 控制 SQL，与 ds preview --raw --limit 1 的 rowCount 比较。--calibration-filter 可多次指定 EQ、BT、IS_NULL、NOT_NULL；同一组条件自动用于控制 SQL 和数据集预览，不手工猜两者范围一致。这验证控制范围的完整输入聚合，不证明用户业务 SQL 的口径。校准不一致或取数前后来源版本/更新时间变化时不写成功 result.json。

默认删掉临时工作区；--keep-workspace 也只留下本次生成的 etl.go 与 aggregate.sql，删除全部 CLI 底稿、身份数据与 metadata。输出必须是新的私有目录，不能覆盖旧结果。与分块脚本共享同 profile 的串行锁、5 秒开始间隔与未知请求标记；超时后停止。汇总留下未知请求时，须另有独立终态证据人工核查，脚本不提供按时间清除的按钮。

```bash
python3 -m unittest discover -s tests -p 'test_etl_preview_aggregate.py'
python3 examples/etl-preview-aggregate/offline_demo.py --out /private/tmp/aggregate-offline
```
